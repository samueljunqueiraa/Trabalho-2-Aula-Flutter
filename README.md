# 📱 Trabalho 2 - Aula Flutter

Este repositório contém o segundo trabalho da disciplina de Desenvolvimento Mobile. O projeto foi desenvolvido em **Flutter**, com suporte multiplataforma (Android, iOS, Web, Desktop).

## 🚀 Tecnologias

- **Linguagem:** Dart
- **Framework:** Flutter
- **Gerenciamento de Pacotes:** Pub

## 📂 Estrutura do Projeto

A organização de pastas segue o padrão oficial do Flutter:

- `lib/`: Código fonte principal (`main.dart` e telas).
- `assets/`: Arquivos estáticos (imagens, fontes, ícones).
- `test/`: Testes unitários.
- `android/`, `ios/`, `web/`: Configurações nativas de cada plataforma.
- `pubspec.yaml`: Arquivo de configuração de dependências.

## 🛠️ Pré-requisitos

- **Flutter SDK** instalado e configurado no PATH.
- **VS Code** (com extensão Flutter/Dart) ou **Android Studio**.

## ▶️ Como Executar

O projeto está configurado para ser executado diretamente pela IDE, que gerencia automaticamente o download de dependências (`pub get`).

### Opção 1: Via VS Code (Recomendado)

1. Abra a pasta do projeto no **VS Code**.
2. Ao abrir, o VS Code deve detectar o arquivo `pubspec.yaml` e solicitará para baixar as dependências (botão "Get Packages" ou download automático).
3. Selecione o dispositivo de emulação no canto inferior direito.
4. Pressione **F5** para iniciar a depuração.

### Opção 2: Via Android Studio

1. Selecione **Open an Existing Project** e aponte para a pasta raiz.
2. Aguarde a indexação e clique em **Pub Get** na barra superior se solicitado.
3. Selecione o emulador e clique no botão **Run** (ícone de Play verde).
